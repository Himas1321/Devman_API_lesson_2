# Утилита для сокращения ссылок
## Описание
Данная программа позволяет получить сокращенную ссылку. Так же возможно получить количество кликов по сокращенной ссылке.

## Пример запуска скрипта
Для запуска скрипта требуется сделать следующее:
1. Получить токен на сайте [VK](https://id.vk.ru/about/business/go/docs/ru/vkid/latest/vk-id/connection/tokens/service-token)
2. В папке со скаченным скриптом создать файл с расширением .env
3. Открыть файл в текстом редакторе и добавить строку 
VK_TOKEN="токен сформированный на сайте VK"
4. Запустить можно следующей командой:
```
python main.py
```
